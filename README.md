## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Neej03/Nexus-Health-AI.git
```

Navigate to the project folder:

```bash
cd Nexus-Health-AI
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm start
```
